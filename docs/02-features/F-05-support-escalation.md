# F-05 Support-escalation preparation

## Goal
Prepare a complete evidence-backed support packet for a merchant to review and send manually.

## Acceptance criteria
- Agent gathers relevant order, payment, timeline, and prior-case evidence.
- Packet distinguishes facts from interpretation.
- Merchant can edit the draft.
- Packet is exportable or copyable.
- No message is sent externally.

## Implementation note

The support packet combines linked order, payment, timeline, and prior-case evidence, separates facts from interpretation, and provides an editable unsent draft with copy support. The workflow is advisory and does not call an outbound messaging or escalation system.
