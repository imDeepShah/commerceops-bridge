# Success metrics

## Product outcomes
- A judge understands the problem and product within 30 seconds.
- The agent completes a multi-step investigation through WebMCP tools.
- No consequential action occurs without explicit merchant approval.
- Every recommendation links to supporting evidence.
- The demo can be reset and replayed reliably.

## Prototype benchmark
Measure the same seeded cases using conventional and WebMCP-assisted workflows: time to resolution, manual interactions, context switches, tool calls, missing fields, and approval points.

Initial target, to be validated rather than assumed: 60–80% lower investigation time.
